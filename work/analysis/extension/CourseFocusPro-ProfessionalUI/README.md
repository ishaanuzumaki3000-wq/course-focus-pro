# Course Focus Pro

## Chrome Web Store Polish Build 1.8.4

Course Focus Pro is a Chrome extension for students who want a clean focus dashboard, saved course links, automatic study analytics, distraction redirects, daily goals, local study music, hydration reminders, and subtle XP/rank progress.

## Current Interface

- Focus: timer, selected course, start/pause/resume/stop controls, daily stats, redirect toggle, and Today's Insight.
- Courses: continue learning, recently viewed, most studied, all courses, and user-created course libraries.
- Analytics: readable bar charts, streaks, goal progress, focus history, XP, level, and rank.
- Daily Goals: automatic system goals for XP plus custom personal goals for organization.
- Music: built-in study sounds and local imported audio.
- Settings: study profile, blocked/support sites, theme, focus defaults, water reminders, sound controls, backups, reset tools, and About information.

## Notes

- Subject analytics are calculated from completed focus sessions.
- Personal tasks do not give XP, so XP stays tied to verified study actions.
- Imported audio files stay local. Browser security may require re-importing files after a restart.
- Allowed/support websites are not redirected during Focus Mode.

## Install

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select this folder.
6. Pin Course Focus Pro from the extensions menu.
